# 🌐 Web Technology and Applications Labs
## CSI315 - Web Technology and Applications Labs by Keletso Joy Ditlhotlhole


A collection of laboratory exercises completed as part of my **CSI315: Web Technology and Applications** course during my BSc Computer Science studies. 🎓💻

## 🌸 About This Repository

This repository documents my practical introduction to web development and web-based application technologies.

The laboratory exercises progressed from building static webpages with **HTML5 and CSS3** to developing dynamic, database-driven applications using **PHP and MySQL**.

The course helped me understand how the different layers of a web application work together, from structuring and styling a webpage to accepting user input, processing information on the server, and storing data in a relational database. 🌐✨

## 📚 Coursework Overview

The laboratory exercises covered both frontend and server-side web development.

The work included:

- Building structured webpages with HTML5
- Styling webpages using CSS3
- Creating tables, links and nested lists
- Working with colours and page layouts
- Creating responsive landing pages
- Using grids, fluid images and media queries
- Embedding multimedia content
- Building and processing web forms
- Writing PHP functions
- Connecting PHP applications to MySQL
- Performing database CRUD operations

## 🧱 HTML5 Foundations

The earlier laboratory exercises introduced the structure and common elements of an HTML5 document.

I worked with:

- Headings and paragraphs
- Tables and table formatting
- Rows and columns
- `colspan` and `rowspan`
- Images and alternative text
- Hyperlinks
- Ordered and unordered lists
- Nested lists
- Metadata
- Character encoding
- Semantic document structure

These exercises helped me understand how HTML provides the underlying structure and meaning of a webpage.

CSS was used to improve the appearance, readability and layout of the webpages.

The coursework included:

- Background colours
- Table borders and spacing
- Padding and alignment
- Link and visited-link styling

Responsive design concepts included:

- Fluid images
- Responsive video
- Media queries
- Navigation elements
- Header and footer sections

## 🐘 Server-Side Programming with PHP

The PHP exercises introduced dynamic, server-side webpage development.

I explored:

- Embedding PHP within HTML
- Variables and basic calculations
- Functions
- Strings and word counting
- Arrays and associative arrays
- Date and time functions
- Processing form submissions

- Producing dynamic HTML output

## 🗄️ PHP and MySQL Integration

The later laboratories introduced database-driven web applications using PHP and MySQL.

The exercises included:

- Establishing a MySQL connection
- Checking whether a connection succeeded
- Executing SQL statements
- Retrieving records
- Counting returned rows
- Displaying database results in a webpage
- Handling database errors
- Closing connections

This connected the frontend, server-side and database concepts covered throughout the course.

## ♻️ CRUD Operations

A major exercise involved implementing the four fundamental database operations:

| Operation | Purpose |
|---|---|
| **Create** | Insert a new record into the database |
| **Read** | Retrieve and display stored records |
| **Update** | Modify an existing record |
| **Delete** | Remove a record from the database |

HTML forms collected the required values, while PHP processed each request and communicated with MySQL.

The applications also used prepared statements and bound parameters for some database operations, introducing a safer way to work with user-supplied values.
